---

## Interview Process

### Round 1 – Technical Interview

* **Duration**: ~60 minutes
* **Format**: Discussion + Coding

**Questions & Topics Discussed**

* Three Rust code snippets were provided; asked to correct and make them work.
* Write a program to check for a Prime Number in Rust.
* Explain Ownership and Borrowing in detail.
* Discuss Rust projects worked on and demonstrate them via GitHub screen sharing.
* Since I wasn't familiar with traits at the time, I was asked to learn from the Rust Book live and implement an example demonstrating trait inheritance.

---

### Round 2 – Take-Home Assignment

* **Duration**: 4 days
* **Format**: Take-Home Assignment

**Assignment Details**

* Create a web server in Rust for a TODO application backend using `axum` (or `actix-web`).
* Implement REST APIs for CRUD functionality: GET, POST, PUT, DELETE.
* No frontend required — APIs can be tested using Postman.

---

### Round 3 – Technical Interview

* **Duration**: ~60 minutes
* **Format**: Discussion + Live Coding

**Questions & Topics Discussed**

* Detailed discussion about the take-home assignment.
* Questions about various HTTP methods.
* Asked to update an existing endpoint to accept more parameters and to create a new endpoint.

---

### Round 4 – HR Round

* **Duration**: ~30 minutes
* **Format**: Behavioral Questions + Salary Discussion

**Questions & Topics Discussed**

* Team collaboration and conflict resolution.

---

## Key Topics Covered

* Trait inheritance

## Outcome

* **Result**: Offer Extended
* **Feedback Received**: No
* **Reflections**: I was able to explain everything clearly and answer almost all questions. The questions were very basic, which is expected for a fresher role.

---

## Tips for Future Candidates

* Focus on core Rust concepts and practice explaining them clearly with examples.
* Build and showcase Rust projects to demonstrate practical knowledge.
* Be prepared to read and learn from documentation on the spot — interviewers at early-stage companies often value learning ability over prior knowledge.
